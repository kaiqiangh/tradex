## Turn, artifact and export construction

Before beginning a model turn, `lib.rs:6035` re-derives the research result using the same producer and compares the **entire typed result** byte-for-byte via equality. A caller replacing the empty research venue bid with a genuine current source bid is rejected with RESEARCH_RESULT_INVALID before model route resolution. Typed supplied fields are not trusted source evidence. TurnSnapshot (`protocol.rs:3355`) contains mode/context/model and references, not a live MarketSnapshot.

ArtifactSave (`protocol.rs:6078`) accepts only existing workspace/thread/turn/item IDs, kind and title, with unknown fields denied. `save_artifact` (`lib.rs:5237`) requires a completed saved turn/item and derives content/provenance from that item; the renderer cannot supply a raw snapshot as artifact content. Research references copied into artifact provenance are bounded IDs/hashes, not raw book values. ArtifactExport (`protocol.rs:6103`) accepts saved artifact identity and destination metadata only. `storage.rs:10585` loads that saved artifact, constructs its manifest and serializes it; it has no ControlPlane observation/Hot read input. Neither legitimate artifact operation can automatically fetch or attach this producer's live book. The public regression also verifies that adding a live snapshot field to either operation is rejected at IPC parsing.

An author/model can write arbitrary text or reference an existing artifact. That is not automatically licensed redistribution, and these paths do not implement universal numeric-text DLP. This argument establishes the absence of an automatic path **from the current source producer** into research/model/turn/artifact/export; it does not promise that generic text can never contain coincidentally equal numbers or manually copied content.
