## Review findings and corrections

Standards review was performed first against the baseline and all new files, then Spec review against task #6, its parent specification, PRD §26.1–26.2 and UI A2/A3/E1/E2/J5. No actionable Standards or task-#6 Spec findings remain after the following confirmed findings were repaired and checked:

1. A provider could JSON-escape a reflected credential into an otherwise valid symbol, bypassing a raw-byte check. A public lifecycle negative case reproduced the leak before the fix. Parsed JSON strings and keys are now checked before any observation is published; the regression passes.
2. Failed initial tests retained their newly saved credentials. They now invalidate probing before cleaning their own reference. Failed cleanup remains `DELETE_PENDING`, visible and retryable; successful cleanup does not touch another connection's credential.
3. Restart could replace a failed cleanup state with `UNCHECKED`, enabling a probe of an abandoned connection. Restart now preserves the cleanup block and missing-credential state. Authentication/network/rate-limit failure and restart/cleanup cases pass.
4. Account overview omitted the equity/balance and arming fields required by UI E1. Those fields are now rendered and the updated browser narrow-window checks pass.
5. With the current macOS keyboard setting, Tab skips native buttons. A visible Command-Return test shortcut was added; Escape remains cancellation. Actual Command-Return validation and synthetic-credential submission passed; Escape returned focus to the Connect trigger. A viewed native screenshot confirmed the focus outline, and Tab/Shift-Tab/Return exercised the restored keyboard target.

Contract/fault checks also cover unknown renderer secret fields, unsupported Alpaca Live, exact review versions, identity mismatch, late results after disconnect/workspace switch, duplicate-account cleanup, missing Keychain items, atomic outbox rollback, malformed/oversized responses and 501-order ID pagination.
